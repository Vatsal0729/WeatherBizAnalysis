Pearson correlation: the exact calculation

Let xᵢ be rainfall in mm and yᵢ be the commercial volume on the same timestamp. Only finite, verified observation pairs enter this calculation.

n = {{ a.n }}
x̄ = Σxᵢ / n = {{ '%.6f'|format(a.xmean) }} mm
ȳ = Σyᵢ / n = {{ '%.6f'|format(a.ymean) }} units

Sxx = Σ(xᵢ − x̄)² = {{ '%.6f'|format(a.sxx) }}
Syy = Σ(yᵢ − ȳ)² = {{ '%.6f'|format(a.syy) }}
Sxy = Σ(xᵢ − x̄)(yᵢ − ȳ) = {{ '%.6f'|format(a.sxy) }}

Sample covariance = Sxy / (n − 1) = {{ '%.6f'|format(a.covariance) }}
sₓ = √[Sxx / (n − 1)] = {{ '%.6f'|format(a.sx) }}
sᵧ = √[Syy / (n − 1)] = {{ '%.6f'|format(a.sy) }}

r = Sxy / √(Sxx × Syy) = {{ '%.6f'|format(a.pearson) }}

Spearman correlation: handling ranks and tied zero-rain days

Rᵢ = rank(xᵢ), Qᵢ = rank(yᵢ)
ρ = PearsonCorrelation(R, Q) = {{ '%.6f'|format(a.spearman) }}

Tied observations receive average fractional ranks. This is essential because zero-rain intervals are frequent in historical weather telemetry.

Ordinary Least Squares (OLS) fitted line

ŷ = b₀ + b₁x
b₁ = Sxy / Sxx = {{ '%.6f'|format(a.slope) }} units per mm
b₀ = ȳ − b₁x̄ = {{ '%.6f'|format(a.intercept) }} units
R² = 1 − Σ(yᵢ − ŷᵢ)² / Syy = r² = {{ '%.6f'|format(a.r2) }}

The slope b₁ quantifies the unadjusted linear change associated with 1 additional mm of precipitation. Holding seasonal and calendar factors constant requires multi-variable econometric controls.

Mathematical foundation of descriptive statistics

Mean: x̄ = Σxᵢ / n
Sample variance: s² = Σ(xᵢ − x̄)² / (n − 1); SD = √s²
Median: middle sorted element (or average of two center values for even n)
IQR = Q₃ − Q₁ (25th and 75th percentiles with linear interpolation)
Tukey fences: [Q₁ − 1.5×IQR, Q₃ + 1.5×IQR]
Group mean = sum of observed activity in bin / observations in bin
Histogram frequency = observation count inside each bin interval

Skewness measures distributional asymmetry; excess kurtosis measures tail thickness relative to a standard Gaussian normal distribution:

zᵢ = (xᵢ − x̄) / s
Skewness = n Σzᵢ³ / [(n − 1)(n − 2)]
Excess kurtosis = n(n + 1) Σzᵢ⁴ / [(n − 1)(n − 2)(n − 3)] − 3(n − 1)² / [(n − 2)(n − 3)]

Sample statistics follow unbiased sample definitions. Positive skew indicates a right tail of peak sales or severe weather days.

Econometric Two-Way Fixed Effects (TWFE) comparison

While unadjusted bivariate correlation pools all observations, the Executive Intelligence platform implements multi-variable fixed-effects regression to isolate weather shocks from recurring day-of-week and seasonal cycles.
